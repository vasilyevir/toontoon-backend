# Лица для съёмки примеров каталога

Отсюда берёт снимки `scripts/shoot_examples.py`. Только отсюда: раньше пул
собирался из всех `source-1.jpg` каталога, и в него попадали пожилые люди и
**шесть фотографий кошек и собак** из `pet_magic` — скрипт не смотрит, кто на
снимке, и кошка в роли исходника для «Train Station» ничем не отличалась бы
от остальных.

Правило (решение Ильи, 2026-09-02): **молодые модельные лица, женские в
приоритете, мужскими разбавляем.** Не пожилые, не обычные. Это правило про
витрину, а не про конвейер: сервис обязан хорошо обрабатывать любое лицо, и
тестировать его надо как раз на обычных — но не отсюда.

`w*` — женские, `m*` — мужские; скрипт чередует их по кругу, чтобы соседи в
ленте не совпадали. Каждое лицо здесь уже показано в витрине как исходник
какой-то карточки — новых людей без спроса сюда не класть.
