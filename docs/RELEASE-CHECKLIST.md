# Что перевернуть до публикации

Не список пожеланий, а перечень настроек, каждая из которых сейчас стоит в
положении «удобно разработчику». По отдельности любая из первых трёх отдаёт
чужой аккаунт.

Собрано 31 августа 2026, проверено по `app/config.py` и по живому серверу.

## 1. Флаги в `.env` — четыре ключа

| ключ | сейчас | нужно | чем грозит, если забыть |
|---|---|---|---|
| `DEBUG` | `true` | `false` | ослабляет всё остальное разом; при нём молчат проверки ниже |
| `EXPOSE_DEV_TOKENS` | `true` | `false` | токены сброса пароля уходят прямо в ответе API |
| `ACCEPT_STOREKIT_TEST_ROOT` | `true` | `false` | подписку себе выпишет кто угодно: тестовый корень Xcode лежит внутри Xcode у всех |
| `APP_KEY_REQUIRED` | `false` | `true` | решение Ильи от 28 августа: подпись запросов включить до релиза |

**Забыть незаметно нельзя.** При старте с `DEBUG=false` сервер кричит в лог
ошибкой о каждом из первых трёх, а шесть тестов в
`tests/test_unsafe_defaults.py` держат саму проверку — включая тест, который
ловит её удаление.

Проверить одной командой:

```bash
PYTHONPATH=. .venv/bin/python -c "
from app.config import settings as s
for имя, есть, надо in (('DEBUG', s.debug, False),
                        ('EXPOSE_DEV_TOKENS', s.expose_dev_tokens, False),
                        ('ACCEPT_STOREKIT_TEST_ROOT', s.accept_storekit_test_root, False),
                        ('APP_KEY_REQUIRED', s.app_key_required, True)):
    print(('OK ' if есть == надо else 'НЕТ'), имя, есть, '→', надо)"
```

`APP_KEY` и `APP_SECRET` при включении `APP_KEY_REQUIRED` должны совпадать с
`Config.xcconfig` приложения, иначе оно перестанет ходить на `/api/*` целиком.

## 2. Домен — блокер, а не настройка

`toontoon.ai` **не резолвится**. С пейвола и из настроек ведут ссылки
`https://toontoon.ai/terms` и `/privacy`; App Review отклоняет заявку на первом
же нажатии такой ссылки (правило 3.1.2). Тексты готовы и лежат в
`content/legal/`, публиковать их пока некуда.

Адреса ссылок собраны в одном месте — `AppConfig` приложения, — так что после
покупки домена правится одна строка.

## 3. Что должно быть сделано в продукте, а не в настройках

Три вещи, о которых политика конфиденциальности вынуждена говорить правду, и
правда неудобна. Подробности — в `content/legal/README.md`.

* ~~**Удаление аккаунта не стирает снимки.**~~ Закрыто 31 августа: файлы
  стираются из хранилища, строки помечаются, книга проводок цела. Три теста.
* ~~**Apple требует удаления внутри приложения**~~ (правило 5.1.1(v)). Закрыто
  31 августа: отдельный блок в настройках с подтверждением.
* **Срока хранения нет вовсе** — ни у снимков, ни у готовых кадров. Сперва надо
  завести срок в продукте, потом записать его в политику, а не наоборот.
