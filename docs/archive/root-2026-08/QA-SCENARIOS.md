## 1. Как читать документ

**Приоритеты:** 🔴 P0 — потеря денег/данных или зависание · 🟡 P1 — заметно ломает UX · 🟢 P2 — edge-case/косметика.

**Колонка «Результат»** заполняется при прогоне:
- ✅ — работает корректно
- ❌ — баг (завести задачу)
- ⚠️ — работает частично / неоднозначно
- — — не проверено

ID сценария = `раздел.номер` (например `2.1`) — для ссылок в багтрекере.
