## ⚠️ Безопасность (прочитай первым)
- GitHub-токен, которым создавался репозиторий, засвечен в переписке.
  **Отзови/пересоздай его** на github.com → Settings → Developer settings →
  Personal access tokens. Для работы над приложением новый Claude должен
  использовать **твой свежий токен**, а не старый.
- Приложению (Трек A) **не нужны никакие ключи провайдеров** (OpenAI, kie.ai,
  Boostyfi, VAPID, Cloudinary). Все они живут только в backend `.env` на сервере
  `/opt/gen-backend/.env` и в приложение попадать не должны.
- В приложение не кладём ничего секретного. Единственная конфигурация — `BASE_URL`
  (не секрет), через `Config.xcconfig` (git-ignored).

## Что уже готово
Приватный репозиторий: **https://github.com/iliyggg/toontoon-ios** (ветка `main`).
Внутри — каркас SwiftUI + полная документация в `docs/`:
- `docs/API.md` + `docs/openapi.json` — весь контракт бэкенда.
- `docs/DESIGN.md` — точные токены дизайна (1:1 с вебом).

(magic-link + Keychain), базовый флоу генерации (тайлы → вопросы → результат).

СЕРВЕР (локальная разработка): base URL = http://193.149.190.155 , API под /api,

АВТОРИЗАЦИЯ (Трек A, без правок бэкенда):
  1) POST /api/auth/magic-link {email} → {devLink}
  2) экран 4-значного кода косметический (бэк OTP не проверяет) — любые 4 цифры
  3) GET devLink с блокировкой редиректа → перехватить Set-Cookie toontoon-session
  4) хранить cookie в Keychain, слать заголовком Cookie: во всех запросах
  Это уже реализовано в Auth/ и Networking/APIClient.swift — переиспользуй.

ЗАДАЧИ (по приоритету, детали в docs/SCREENS.md):
  1. Создать Xcode-проект, подключить исходники из ToontoonApp/, настроить
     Config.xcconfig и шрифт Instrument Sans (Resources/Fonts).
  2. Довести лендинг: анимированная карусель из 5 карточек (coverflow-веер,
     центр scale 1.14, боковые повёрнуты ±15/±40° и размыты, интервал ~2.8с).
  3. Экран генерации (главный, веб-референс generate/page.tsx, 3000 строк):
     - верхняя панель: баланс TOONTOON, бургер → боковой drawer с историей чатов;
     - каталог тайлов по категориям (image/postcard/announcement/video);
     - quick-reply флоу (вопросы тайла пилюлями, поддержка allow_custom);
     - свободный чат через POST /api/chat (ассистент предлагает тайл);
     - генерация: image ~15–45с (url в ответе), video → status queued →
       polling GET /api/generations/{id} каждые ~5с до ~15 мин → result_url;
     - пузыри чата: текст/картинка/видео-плеер (AVKit)/открытка (текст поверх
       картинки, см. CardTextOverlay)/ошибка с Retry;
     - плавающий индикатор активной генерации;
     - тайлы с needs_photo: сначала POST /api/uploads, затем photo_url в /generate.
  4. Профиль/баланс/история транзакций (/api/auth/me, /balance, /transactions).

ОГРАНИЧЕНИЯ:

Действуй итеративно: сначала запусти то, что есть, убедись что вход и генерация
картинки работают против http://193.149.190.155, потом наращивай экраны.

## Трек B (на будущее, требует правок бэкенда)
Правильный мобильный OAuth (Boostyfi/Google): бэк должен отдавать session/токен
в JSON вместо редиректа на веб, зарегистрировать схему `toontoon://auth/callback`,
приложение — `ASWebAuthenticationSession` + PKCE. См. `docs/AUTH.md`.
