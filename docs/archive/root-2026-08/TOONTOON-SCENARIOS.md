# TOONTOON — Полный каталог сценариев генерации

> **4 типа контента · 34 тайла · ~120 вопросов · ~480 вариантов ответов**  
> Каждый тайл = конкретный сценарий с набором уточняющих вопросов.  
> `[custom]` = можно написать свой вариант.  
> ⭐ = featured (показывается первым в интерфейсе).  
> Стоимость: изображения/открытки/объявления — **1 TOONTOON**, видео — **2 TOONTOON**.
