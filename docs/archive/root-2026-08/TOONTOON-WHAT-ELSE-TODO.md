# TOONTOON iOS — что ещё можно сделать (мастер-промт для консистентности)

Единый документ: текущее состояние + стандарты, которых держаться, чтобы **всё
в приложении было одинаковым** (дизайн, безопасность, авторизация, аналитика),
+ полный список оставшихся задач. Можно отдать второму Claude как промт.

---

## ЧАСТЬ 1. Что уже готово (не переделывать, переиспользовать)
- **Дизайн-система** — `DesignSystem/Theme.swift`: точные токены (цвета/отступы/
  радиусы/шрифт Instrument Sans). Полная вёрстка всех экранов — `MOBILE-DESIGN-FULL.md`.
- **Сеть** — `Networking/APIClient.swift` (+ `Models.swift`), HTTPS с пиннингом.
- **Безопасность** — `Networking/APISecurity.swift`, `App/AppConfig.swift`,
  сервер на HTTPS (self-signed + пиннинг). Детали — `SECURITY.md`.
- **Авторизация** — email+пароль: `Auth/AuthManager`, экраны Login/Register/
  Verification(stub), общие компоненты `AuthComponents.swift`. Бэкенд:
  `/api/auth/register|login` (Argon2, rate-limit). См. `AUTH-SCREENS.md`.
- **Аналитика** — SDK-независимый слой `Analytics/*`: события, согласие, две
  реализации: `ServerAnalyticsClient` (наш `/api/events`, работает сейчас) и
  `TelemetryDeckClient` (по App ID). См. `ANALYTICS-AUDIT.md`.
- **Ассеты** — все SVG/PNG/лого в `Resources/Images` (assets/ + landing/).

## ЧАСТЬ 2. СТАНДАРТЫ — держаться во всём (чтобы было одинаково)
1. **Только токены дизайна** из `Theme.swift`. Никаких «своих» цветов/отступов.
   Тёмная тема, портрет, шрифт Instrument Sans, скругления 8/12/16/24/40/pill.
2. **Все сетевые вызовы — через `APIClient`** (никаких «голых» URLSession):
   так работает пиннинг, app-key и подпись автоматически.
3. **Экраны-карточки auth-типа — через `AuthComponents`** (AuthCard/AuthField/
   AuthPrimaryButton), чтобы вход/регистрация/верификация были единообразны.
4. **Любое новое действие → событие аналитики** из каталога `AnalyticsEvent`
   (snake_case, object_action, БЕЗ PII/содержимого промптов). Новые — добавлять
   в enum, не хардкодить строки.
5. **Ошибки API** показывать единообразно (текст из `APIError`), коды 402/429/
   503/401 — понятные сообщения пользователю.
6. **Секреты — только в `Config.xcconfig`** (git-ignored), в коде — плейсхолдеры.
7. **Приватность:** ничего не отправляем без согласия (ConsentManager); privacy-
   manifest и Nutrition Labels держать синхронно.
8. **Именование:** экраны `*View`, VM `*ViewModel`, модели = snake_case под бэкенд.
