# Архив

Снимки состояния на дату: аудиты, отчёты, разборы. **Не источник правды** —
они описывают, как было в момент написания.

Актуальное лежит в `docs/`: контракт в API.md и openapi.json, настройки
в CONFIG.md, решения в adr/, изменения в CHANGELOG.md.

- `root-2026-08/` — 35 документов, лежавших в папке проекта без git. Описывают
  продукт до переезда на PostgreSQL и до отказа от веба; больше половины были
  копиями файлов из репозитория приложения, шесть пар успели разойтись.
- `2026-06-generation-visual-fixes.md` — разбор визуальных дефектов генерации.
