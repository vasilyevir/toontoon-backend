## 1. Конфигурация и переменные окружения

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| FE-1.1 | Write-токены не публичны | 🔴 | `NEXT_PUBLIC_`/`VITE_`/`REACT_APP_` с write-token | Только read-токены на клиенте |
| FE-1.2 | Нет захардкоженных ключей | 🟠 | Fallback с реальным API-ключом/ID в коде | Через env, без реальных дефолтов |
| FE-1.3 | `.env*` в `.gitignore` | 🟠 | Все варианты env-файлов | Игнорировать все |
| FE-1.4 | Разные токены на среды | 🟡 | Один токен на stage/prod | Per-env значения |
| FE-1.5 | Секреты не в бандле | 🟠 | Grep секретов в собранном JS | Секреты — только backend |
| FE-1.6 | Feature flags / скрытые пути | 🟢 | Скрытая функциональность видна в бандле | Не полагаться на клиентское скрытие |

## 2. Debug-инструменты и артефакты сборки

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| FE-2.1 | Debug-инструменты не в проде | 🟡 | `eruda`, `vconsole`, react-devtools в prod | Только devDependencies |
| FE-2.2 | Source maps отключены | 🟡 | `.map` в проде раскрывают исходники | `productionBrowserSourceMaps: false` |
| FE-2.3 | `console.log` чувствительного | 🟢 | TX hash, ответы API, PII в консоли | Убрать/strip в билде |
| FE-2.4 | Комментарии с секретами | 🟢 | TODO/креды в комментариях бандла | Чистка при сборке |
| FE-2.5 | Sourcemaps не публично доступны | 🟡 | `.map` доступны по URL | Не деплоить `.map` / закрыть |

## 3. Third-party скрипты и SRI

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| FE-3.1 | SRI на CDN-ассеты | 🟡 | `<script src="cdn...">` без `integrity` → подмена | Добавить `integrity` + `crossorigin` |
| FE-3.2 | Минимум third-party | 🟡 | Много внешних скриптов = attack surface | Self-host критичных ассетов |
| FE-3.3 | Аналитика/трекеры | 🟢 | Утечка PII в трекеры | Аудит данных, отправляемых в трекеры |
| FE-3.4 | Supply chain npm | 🟠 | Скомпрометированный пакет в бандле | Lock-файлы, аудит (см. [21](./21-dependency-supply-chain.md)) |
| FE-3.5 | iframe / встраивания | 🟡 | Небезопасные `<iframe>` без sandbox | `sandbox` атрибут |

> ⚠️ **Урок из практики:** CDN-ассеты UI-библиотеки без SRI. Подмена файла на CDN → выполнение чужого кода.
> `integrity="sha384-..."` или self-host.

## 4. Web3 / кошельки (клиент)

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| FE-4.1 | `feeLimit` адекватный | 🟠 | > 1000 TRX → баг/malicious контракт сожжёт fee | Разумный лимит |
| FE-4.2 | Contract address из env | 🟡 | `isMainnet ? a : b` — ошибка флага → mainnet-деньги на testnet | Явная конфигурация из env |
| FE-4.3 | Allowance не MAX_UINT256 | 🟡 | `approve(MAX_UINT256)` → неограниченный доступ | Approve только на нужную сумму |
| FE-4.4 | Проверка tx receipt | 🟡 | Нет polling статуса после `send()` | Проверять receipt/`status` |
| FE-4.5 | Wallet disconnect чистит auth | 🟠 | Смена кошелька не логаутит | Logout + очистка токенов |
| FE-4.6 | Wallet mismatch detection | 🟡 | Текущий кошелёк ≠ профильный | Сверять и предупреждать |
| FE-4.7 | Подпись понятна пользователю | 🟡 | Слепая подпись непонятного сообщения | Человекочитаемое сообщение (EIP-712) |
| FE-4.8 | Нет приватных ключей на клиенте | 🔴 | Ключи/сиды в JS/localStorage | Только через кошелёк-провайдер |

## Быстрые команды проверки

```bash
# Публичные переменные с секретами
rg "NEXT_PUBLIC_|VITE_|REACT_APP_" | rg -i "secret|token|key|sk_|private"

# Debug-инструменты
rg -i "eruda|vconsole|react-devtools|redux-devtools" package.json

# Source maps
rg -i "productionBrowserSourceMaps|sourceMap|devtool" next.config.* vite.config.* webpack.config.*

# SRI
rg "<script[^>]*src=" | rg -L "integrity"

# Web3
rg -i "feeLimit|approve\(|MAX_UINT|MaxUint256|contractAddress"

# Секреты в собранном бандле (после build)
rg -i "(sk_|pk_live|AIza|AKIA)[0-9A-Za-z]" dist/ build/ .next/ 2>/dev/null
```
