# 06 — Валидация входных данных

> Проверка того, что каждое поле, приходящее от клиента, валидируется по типу, диапазону, формату и
> бизнес-смыслу — до использования. Особый фокус: числа/деньги, адреса, границы, canonicalization.

**Легенда:** 🔴 Critical · 🟠 High · 🟡 Medium · 🟢 Low · ⚪ Info
**OWASP:** A03/A04 · **ASVS:** V5 · **CWE:** 20, 190, 191, 682, 1284

## 1. Числа и деньги

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| VAL-1.1 | Отрицательные суммы | 🔴 | `amount` без `> 0` → отрицательный вывод/покупка | Проверять `amount > 0` на всех путях |
| VAL-1.2 | Нулевые суммы | 🟡 | `amount == 0` создаёт мусорные записи | Отклонять/игнорировать нули |
| VAL-1.3 | Decimal, не float | 🟠 | float для денег → ошибки округления | `Decimal`; JSON parse с `parse_float=Decimal` |
| VAL-1.4 | Decimal overflow | 🟠 | `Decimal("9"*30)` без `max_digits` | `max_digits`/`decimal_places` + валидатор |
| VAL-1.5 | Integer overflow | 🟡 | `int(amount * 10**18)` при больших суммах | Проверка границ, big-int |
| VAL-1.6 | Точность/квантизация | 🟡 | Больше знаков, чем поддерживает актив | Квантизация по `precision` |
| VAL-1.7 | Верхняя граница суммы | 🟠 | Нет max → аномально большие операции | Разумный max + алерт |
| VAL-1.8 | Знак в admin-путях | 🟡 | Merchant-путь проверяет, admin — нет | Централизованная валидация во всех путях |
| VAL-1.9 | Деление на курс/ноль | 🟠 | `amount / rate` при `rate == 0` | Запрет `rate <= 0`, обработка |

> ⚠️ **Урок:** валидация `amount > 0` часто есть в одном сервисе (merchant payout), но отсутствует в
> admin/internal путях, в `Model.objects.create()` и на уровне БД. Проверяй **все** пути записи и
> добавляй `MinValueValidator` на модель + DB-constraint.

## 2. Строки, адреса, идентификаторы

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| VAL-2.1 | Валидация email | 🟡 | Некорректный/инъекционный email | Строгий валидатор, нормализация |
| VAL-2.2 | Blockchain-адрес | 🟠 | Некорректный адрес кошелька | Формат + checksum (EIP-55, base58check) |
| VAL-2.3 | Модель-уровень валидатор | 🟠 | Валидация только в форме/сервисе, не в модели | Валидатор на поле модели |
| VAL-2.4 | UUID/ID формат | 🟡 | Невалидный ID → ошибки/enumeration | Валидировать формат |
| VAL-2.5 | Длина строк | 🟡 | Нет `max_length` → раздувание/DoS | Лимиты длины |
| VAL-2.6 | Enum/choices | 🟡 | Произвольное значение статуса/типа | Строгий whitelist значений |
| VAL-2.7 | Нормализация Unicode | 🟢 | Homoglyph/спуфинг в username | NFKC-нормализация, запрет смешанных скриптов |
| VAL-2.8 | JSON-поля | 🟡 | Произвольный контент в `metadata` (JSONField) | Схема/валидация содержимого |

## 3. Границы и лимиты

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| VAL-3.1 | Размер тела запроса | 🟡 | Нет лимита → OOM гигантским JSON | `DATA_UPLOAD_MAX_MEMORY_SIZE`, `client_max_body_size` |
| VAL-3.2 | Глубина вложенности JSON | 🟡 | `{"a":{"b":{...}}}` → stack overflow парсера | Лимит глубины |
| VAL-3.3 | Размер массивов/коллекций | 🟡 | Огромные массивы в batch | Max количество элементов |
| VAL-3.4 | Pagination limits | 🟡 | `?page_size=999999` → дамп БД | Серверный `max_page_size` |
| VAL-3.5 | ReDoS | 🟡 | Regex с catastrophic backtracking `(a+)+$` | Безопасные regex / RE2 / таймаут |
| VAL-3.6 | Числовые диапазоны | 🟡 | `?limit=-1`, отрицательные индексы | Проверка min/max |

## 5. Canonicalization и кодировки

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| VAL-5.1 | Path canonicalization | 🟠 | `../`, `%2e%2e`, unicode-обход | Нормализация + проверка префикса |
| VAL-5.2 | Двойное кодирование | 🟡 | `%252e` обходит фильтр | Декодировать один раз, потом валидировать |

| VAL-5.4 | Кодировка charset | 🟢 | Смешанные кодировки обходят фильтры | Явный UTF-8, нормализация |

## Быстрые команды проверки

```bash
# Проверки суммы
rg "amount|price|value" -l --type py | xargs rg -L "> 0|>= 0|MinValueValidator|<= 0"
rg "float\(" --type py    # деньги через float — плохо

# max_digits / decimal
rg "DecimalField\(" --type py | rg -v "max_digits"

# Сериализаторы без строгости
rg "extra\s*=|forbid|additionalProperties" 

# ReDoS-подозрения
rg "re\.(compile|match|search)\(" --type py

# Лимиты тела/страницы
rg -i "MAX_MEMORY_SIZE|max_page_size|client_max_body_size|PAGE_SIZE"
```
