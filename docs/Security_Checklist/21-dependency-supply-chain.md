## 1. Известные уязвимости (CVE/SCA)

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| DEP-1.1 | CVE в зависимостях | 🟠 | `pip-audit`/`npm audit`/`safety` находят уязвимости | Обновить/пропатчить |
| DEP-1.2 | Устаревшие мажоры | 🟡 | Flask/Django/express на старых линиях | План обновления |
| DEP-1.3 | Транзитивные зависимости | 🟡 | Уязвимость в под-зависимости | Аудит дерева, override |
| DEP-1.4 | Устаревший base image | 🟠 | Образ с CVE (напр. старая нода/ОС) | Обновление base image |
| DEP-1.5 | EOL-компоненты | 🟠 | Компоненты без поддержки | Миграция на поддерживаемые |

## 2. Управление версиями и lock-файлы

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| DEP-2.1 | Lock-файлы закоммичены | 🟠 | Нет `poetry.lock`/`package-lock.json` | Коммитить lock |
| DEP-2.2 | CI использует lock | 🟠 | `npm install` вместо `npm ci` | `npm ci`/`pip install -r` с хэшами |
| DEP-2.3 | Pinned versions | 🟡 | `>=`/`*` в прод-зависимостях | Точные версии/`~=`/`^` + lock |
| DEP-2.4 | Hash-pinning | 🟡 | Нет проверки хэшей пакетов | `--require-hashes`/lock с integrity |
| DEP-2.5 | Детерминированная сборка | 🟡 | Незапиненные критичные (`cryptography`) | Запинить всё |

## 4. Вредоносные пакеты

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|

## Быстрые команды проверки

```bash
# Python
pip-audit -r requirements.txt
safety check --full-report
# Node
npm audit --audit-level=high
# или yarn/pnpm audit

# Lock-файлы
ls poetry.lock package-lock.json yarn.lock pnpm-lock.yaml Pipfile.lock 2>/dev/null

# Незапиненные версии
rg ">=|\*" requirements.txt pyproject.toml 2>/dev/null
rg "\"\^|\"~|\"\*\"|latest" package.json

# post-install скрипты
rg -i "postinstall|preinstall|prepare" package.json

# SRI отсутствует
rg "<script[^>]*src=[\"']https?://" | rg -L "integrity"

# Образы без digest
rg "image:\s*[^@]+$" -g "docker-compose*.yml" Dockerfile
```
