## 1. Object Storage (S3 / MinIO / GCS / Blob)

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| CLD-1.1 | Нет публичного LIST/READ | 🔴 | Публичный бакет → массовая утечка (PII/фото) | Приватный бакет, `BlockPublicAccess` |
| CLD-1.2 | Presigned URL для выдачи | 🟠 | Публичные прямые ссылки | Presigned URL с TTL |
| CLD-1.3 | Bucket policy минимальна | 🟠 | `*`/`allUsers`/`AllUsers` в политике | Явные принципалы |
| CLD-1.4 | Шифрование at-rest | 🟠 | Нет SSE | SSE-S3/SSE-KMS |
| CLD-1.5 | Версионирование/immutability | 🟢 | Нет защиты от удаления | Versioning + Object Lock для бэкапов |
| CLD-1.6 | Раздельные бакеты по чувствительности | 🟡 | PII и публичное в одном бакете | Разделение + разные политики |
| CLD-1.7 | CORS бакета | 🟡 | `*` CORS на бакете | Явный allowlist |
| CLD-1.8 | Логирование доступа | 🟢 | Нет access-логов бакета | Включить |

> ⚠️ **Урок из практики:** публичный бакет объектного хранилища с LIST+READ → тысячи UUID пользователей и их фото
> (GDPR-инцидент). Хранилище — приватное; выдача через presigned URL; блокировка публичного доступа.

## 5. Сеть и периметр

|---|----------|-------|---------------------|---------------|
| CLD-5.1 | Security groups минимальны | 🟠 | `0.0.0.0/0` на служебных портах | Минимальные правила |
| CLD-5.2 | Приватные подсети для БД | 🟠 | БД в публичной подсети | Private subnet + bastion |
| CLD-5.3 | WAF на публичном периметре | 🟢 | Нет WAF | WAF (managed rules) |
| CLD-5.4 | DDoS-защита | 🟢 | Нет защиты | Cloud DDoS protection |

## Быстрые команды проверки

```bash
# Публичные бакеты / политики в конфигах и IaC
rg -i "public-read|public-read-write|allUsers|AllUsers|BlockPublicAccess|acl\s*=\s*['\"]public"
rg -i "0\.0\.0\.0/0|SecurityGroup|ingress|cidr_blocks"

# Захардкоженные облачные креды
rg "AKIA[0-9A-Z]{16}|aws_secret_access_key|GOOGLE_APPLICATION_CREDENTIALS"

# Metadata SSRF
rg -i "169\.254\.169\.254|metadata\.google|IMDS|instance-data"

# IaC scanning
checkov -d . ; tfsec . ; trivy config .
```
