# 12 — Загрузка файлов

> Загрузка файлов — вектор RCE (через исполняемые файлы), XSS (SVG/HTML), path traversal, DoS
> (zip/decompression bomb) и хранения вредоносного контента.

**Легенда:** 🔴 Critical · 🟠 High · 🟡 Medium · 🟢 Low · ⚪ Info
**OWASP:** A04/A05 · **CWE:** 434, 22, 400, 79, 494

## 1. Валидация типа и содержимого

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| UP-1.1 | Тип по magic bytes | 🟠 | Валидация только по расширению/`Content-Type` | `python-magic`/`filetype`, проверять реальный тип |
| UP-1.2 | Whitelist типов | 🟠 | Blacklist расширений (обходится) | Строгий allowlist разрешённых типов |
| UP-1.3 | Двойные расширения | 🟠 | `evil.jpg.php`, `evil.php.jpg` | Нормализация, allowlist последнего расширения |
| UP-1.4 | Полиглоты | 🟡 | Файл валиден как картинка И как скрипт | Ре-энкодинг изображений |
| UP-1.5 | Соответствие типа и содержимого | 🟡 | `Content-Type: image/png` но реально скрипт | Сверять заявленный и реальный тип |

## 2. Имя файла и path traversal

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| UP-2.1 | Path traversal в имени | 🟠 | `../../etc/passwd`, `..\\` в filename | Sanitize; генерировать UUID-имя |
| UP-2.2 | Null-byte | 🟡 | `file.php\x00.jpg` | Отклонять null-байты |
| UP-2.3 | Абсолютные пути | 🟡 | `/etc/...` в имени | Только basename, свой путь |
| UP-2.4 | Перезапись файлов | 🟠 | Коллизия имён перезаписывает чужое | Уникальные имена (UUID) |
| UP-2.5 | Unicode/спецсимволы | 🟢 | Обфускация пути | Нормализация имени |

## 3. Хранение и выдача

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| UP-3.1 | Хранение вне webroot | 🟠 | Файлы напрямую исполняемы веб-сервером | S3/отдельный домен/CDN, не исполняемая директория |
| UP-3.2 | `Content-Disposition` | 🟡 | Файл открывается в браузере (исполнение) | `attachment` для скачиваемых |
| UP-3.3 | Правильный `Content-Type` при выдаче | 🟡 | Отдаётся с типом, вызывающим исполнение | Безопасный тип + `nosniff` |
| UP-3.4 | Приватность доступа | 🟠 | Публичный доступ к приватным файлам (IDOR/enum) | Проверка прав / presigned URL |
| UP-3.5 | Отдельный домен для загрузок | 🟡 | Загрузки на основном домене → cookie/XSS-риск | Изолированный домен без cookie |
| UP-3.6 | Публичные бакеты | 🔴 | S3/MinIO с публичным LIST/READ → массовая утечка | Приватный бакет + presigned URL |

> ⚠️ **Урок из практики:** публичный бакет объектного хранилища с LIST+READ → тысячи UUID пользователей и их фото (GDPR-инцидент).
> Хранилище загрузок должно быть приватным; выдача — через presigned URL. См. [20](./20-cloud-security.md).

## 4. Размер и DoS

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| UP-4.1 | Max размер файла | 🟡 | Нет лимита → disk exhaustion | Серверный лимит + лимит прокси |
| UP-4.2 | Zip/decompression bomb | 🟡 | 42 KB → 4.5 PB при распаковке | Лимит размера после распаковки |
| UP-4.3 | Лимит количества файлов | 🟡 | Массовая загрузка | Лимит на запрос/пользователя |
| UP-4.4 | Image bomb (пиксели) | 🟢 | Огромные размеры изображения → OOM | Лимит размеров/пикселей |
| UP-4.5 | Таймаут обработки | 🟢 | Долгая обработка блокирует воркеры | Таймаут + очередь |

## 5. Активный контент и malware

| # | Проверка | Крит. | Что искать / вектор | Как исправить |
|---|----------|-------|---------------------|---------------|
| UP-5.1 | SVG XSS | 🟡 | SVG с `<script>` подаётся inline | Санитизация / не `image/svg+xml` inline |
| UP-5.2 | HTML/JS upload | 🟠 | Загрузка `.html` → XSS на домене | Запрет / изолированный домен |
| UP-5.3 | Office/PDF макросы | 🟡 | Документы с активным содержимым | Скан/предупреждение |
| UP-5.4 | Antivirus / malware scan | 🟡 | Нет сканирования загрузок | ClamAV или аналог |
| UP-5.5 | Ре-энкодинг изображений | 🟢 | Метаданные/встроенный код | Пересохранение (strip EXIF) |

## Быстрые команды проверки

```bash
rg "request\.(FILES|files|file)|UploadedFile|InMemoryUploadedFile|multipart" --type py
rg "\.save\(.*filename|os\.path\.join\(.*filename|secure_filename" --type py
rg -i "content-disposition|content-type.*svg|magic|filetype|python-magic" 
rg -i "MAX_UPLOAD|FILE_UPLOAD_MAX|client_max_body_size|MAX_CONTENT_LENGTH" 

# Публичные бакеты (в конфигах)
rg -i "public-read|ACL.*public|BlockPublicAcls|allUsers|AllUsers" 
```
